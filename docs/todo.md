当前前台的 `articleImageUrl` 仅作为旧内容迁移期间的过渡兼容。后续通过修改文章内容统一图片路径，完成迁移和图片检查后再移除前台兼容。

- [ ] 按 Markdown 结构识别图片引用，避免误改代码块、普通链接或示例内容；拒绝越出文章媒体目录的相对路径。
- [ ] 修改前备份原始正文和译文，支持预检并输出变更清单；确认除图片地址替换外，正文、译文及其关联信息保持一致。
- [ ] 核对规范化后的图片地址与服务器媒体文件，验证前台原文/译文、后台预览和 Feed 的图片显示，并补充迁移测试。
- [ ] 在内容迁移和图片检查通过后，移除前台 `articleImageUrl` 路径补齐逻辑及文章 ID 传递，调整测试以验证正文中的规范化图片地址可直接渲染。
