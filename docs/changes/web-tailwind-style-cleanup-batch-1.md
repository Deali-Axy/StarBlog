# apps/web Tailwind 第一批整理

日期：2026-11-18。对应 [样式审计](web-tailwind-style-audit.md)。

## 结果与范围

第一批整理了 33 个业务源文件中的 314 处样式表达：300 处任意属性转换为对应工具类，另有 14 处 rem 间距任意值转换为标准间距类。博客占 266 处，其余为首页、布局和 Marquee。

| 指标 | 改造前 | 改造后 |
| --- | ---: | ---: |
| 任意属性出现次数 | 496 | 196 |
| 含方括号的有效类名出现次数 | 1,814 | 1,783 |
| 不同的任意 min/max 断点定义 | 12 | 12 |
| important 类名出现次数 | 51 | 51 |
| 自定义变量声明出现次数 | 111 | 111 |

任意属性减少约 60.5%。固定像素、不等宽网格和运行时计算仍使用任意值；拆分 padding 也会增加工具类数量，因此方括号总数不是本批的完成指标。

## 主要变化

- 定位、层级、颜色、透明度、flex、网格、行高、字距、外边距及内边距改用对应的工具类。
- `[animation:none]` 改为 `animate-none`，`[scroll-behavior:auto]` 改为 `scroll-auto`，原先的响应式、后代选择器及 `!` 均保留。
- `[grid-template-columns:30px_minmax(0,_1fr)]` 改为 `grid-cols-[30px_minmax(0,_1fr)]`，保留实际列定义。
- `[padding:22px_26px_32px]` 改为 `pt-[22px] px-[26px] pb-[32px]`；`[padding-block:24px_32px]` 改为 `pbs-[24px] pbe-[32px]`。固定像素没有换成 rem，逻辑方向也保留。
- `.5rem`、`1rem`、`1.25rem` 等可由当前标准间距直接表达的值，使用 `gap-2`、`px-4`、`p-5` 等工具类。

33 个业务文件经过 TypeScript AST 结构对照，除字符串和说明性注释外，语法结构保持一致。布局分支、JSX 节点、数据和交互逻辑没有调整。断点数值、主题 token、字号尺度、hover 匹配方式及 `&&` 的优先级职责均保留；padding 拆分会使某些前缀在扫描中重复计数。

## 有意保留的声明

4 处标题行高继续使用显式 CSS 属性，位于两个 archive 列表及 index 紧凑列表。浏览器对照确认：换成 `leading-[…]` 会设置 `--tw-leading`，进而改变响应式 `text-*` 和高优先级紧凑字号的行高回退。后续整理独立视图时再处理，代码中已补充原因。

`[transition:none]` 继续保留。标准 `transition-none` 只设置 `transition-property`，原来的简写还重置 duration、timing-function、delay 等参数。本批保留完整的重置行为。复杂过渡简写、字体简写、背景/边框简写、阴影组合，以及两处与其他定位值叠加的 inset 简写也没有强行拆分。

`calc()`、`env()`、自定义主题变量和必要的特殊属性继续按原职责使用。设计尺度统一和组件规则叠加的处理留给后续批次。

## 验证

- 全项目 ESLint：0 错误；2 条既有图片 alt 警告，均位于 `article-cover.tsx`。
- TypeScript 检查通过；Next.js 默认 Turbopack 生产构建通过，包括构建内的 TypeScript 检查及页面生成。
- `node --test tests/*.test.mjs`：10 个测试文件全部通过，涵盖文章、博客导航、首页、摄影、搜索、SEO 和架构。
- 现有 .NET Playwright 的 `BlogNavigationTests`、`BlogChromeTests`、`HomeCustomizationTests`：62 项全部通过，未跳过测试。
- 重新运行只读扫描：没有发现无法编译的待核对候选；所有新增工具类在替换前也经过当前 Tailwind 4.3.3 编译确认。
- 采集并对照 68 个博客列表/紧凑列表、三套首页、文章、风格菜单和首页设置场景，覆盖 375、768、1440 宽度及明暗主题。初轮发现的标题行高变化已通过保留相关声明消除。其余对照中的随机照片标题、相关推荐摘要有数据差异，未将这些动态内容当作像素完全一致的证据。
- 另补充 54 个场景：639/640、1023/1024、1119/1120、1199/1200 宽度下的三套博客与两种列表，以及普通动态效果模式。最终元素布局和选取的计算样式对照为零差异。

浏览器验证使用 `/tmp/starblog-tailwind-batch1.db` 的数据库副本，未写入原数据库。对照清单、截图及详细差异位于 `/tmp/starblog-tailwind-batch1-browser`，属于临时验证产物。

## 浏览器回归测试的维护

为完成现有测试的验证，同时修正了两份回归文件中的过期假设：

- 清除焦点时不再点击 `sr-only` 的折页标题；保留焦点返回等原有断言。
- 工作台列表页按照已有实现断言不渲染页脚；文章页仍检查页脚，并保留其他方案的页脚导航及回到顶部检查。
- 无效布局参数按照现有默认值 `editorial` 回退。
- 键盘打开风格菜单前，等待既有 hydration 门禁启用按钮。

这些更新对应改造前已有的页面行为，没有调整业务代码来迎合测试。
